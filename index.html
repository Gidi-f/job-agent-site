job-agent

job-agent is a private tool that Gidi Fisher built for a personal job search. It is used only with Gidi's own Google account and is not offered to anyone else.

Once a day it reads job-alert emails, filters the listings by personal criteria, and writes the matching ones to a private Google Sheet.

Privacy policy

Last updated: 1 November 2026

What the tool accesses

  • Gmail, read-only. The tool requests only the messages under one label, which holds job-alert emails. It cannot send, change or delete email.
  • Google Sheets. The tool writes job listings to one spreadsheet in the same account.

How the data is used

  • The tool takes the job title, company, location and similar short details from each alert email.
  • Those job details, together with a short profile of the job seeker, are sent to Anthropic's Claude API to score how well each job fits. Whole emails are not sent.
  • The results are stored in the private Google Sheet.

Sharing

The data is not sold, is not used for advertising, and is not shared with anyone apart from the Anthropic scoring step described above.

Access and removal

Access tokens are kept private and are never published. Access can be removed at any time from the Google Account permissions page.
